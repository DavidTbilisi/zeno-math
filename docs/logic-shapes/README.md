# Logic shapes

Four Excalidraw drawings of the shapes logical reasoning runs on, one panel per shape.
Open one on a Zeno board with the menu's **Open** button (or drag the file onto the board).

| File | Panels |
|---|---|
| `logic-gate-shapes.excalidraw` | proof silhouette · overlapping regions (Venn/Euler) · truth table · bins vs slots · bar model · from logic grid to slots |
| `logic-shapes-beyond-the-gate.excalidraw` | argument map · square of opposition · conditional square · quantifier arrows · proof tree · possible worlds |
| `logic-shapes-deduction-extras.excalidraw` | truth tree · validity vs soundness · syllogism figures · Toulmin model · logic gates |
| `logic-shapes-under-uncertainty.excalidraw` | Bayes dot grid · probability tree · Mill's methods · analogy mapping |

These are copies. The source is the Neural-OS-Research wiki
(`Excalidraw/Logic_*.excalidraw.md`), generated by `tools/logic_shapes_excalidraw.py`;
regenerate there and copy again rather than editing these by hand.
